# Package Manifests

Generated on 2026-06-09 before migrating from Fedora to Ubuntu.

- `fedora-userinstalled-names.txt`: shorter Fedora user-installed package name list.
- `fedora-userinstalled-with-versions.txt`: user-installed Fedora packages with versions.
- `rpm-all-installed.tsv`: complete RPM database package list.
- `flatpak-apps.tsv`: installed Flatpak apps.
- `flatpak-remotes.tsv`: configured Flatpak remotes.
- `npm-global.txt` and `npm-global.json`: globally installed npm packages.
- `python-user-freeze.txt`: user-site Python packages from `pip3 list --user --format=freeze`.
- `pipx-list.txt`: pipx inventory; empty because no pipx apps are installed.
- `dnf-repolist-enabled.txt`: enabled Fedora repositories at backup time.
- `dnf-history-list.txt`: DNF history summary.
- `systemd-user-enabled-units.txt`: enabled user systemd units.
- `systemd-user-running-services.txt`: running user systemd services at backup time.

Ubuntu package names do not always match Fedora names. Use these files as an inventory and translate package names as needed.
